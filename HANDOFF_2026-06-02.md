## Research Pain Point

The paper target should not be written as "PINN + GNN + TCN". The actual pain point is:

```text
In sparse, noisy, and disrupted traffic reconstruction, simplified traffic physics is not uniformly reliable.
Fixed or globally weighted physics losses can locally misguide reconstruction when sensors fail, data are noisy, incidents occur, or the traffic state becomes non-periodic.
```

The method claims to solve:

```text
When should physical evidence be trusted, when should temporal/data-driven evidence dominate, and how can correction avoid harming a strong reconstructor?
```

The most stable story is:

```text
LiteTrust-FMG treats physics as region-aware residual evidence and utility verification, not as a blindly enforced global loss.
It keeps a strong data-driven reconstruction core, then uses physics residual banks, temporal evidence banks, and failure-mode guards to decide where correction is useful and where correction should be suppressed.
```

## Method Components

Current V5 has these components:

1. Strong reconstruction core:
   - Official MagiNet output is used as the base reconstruction.
   - MagiNet is still an external baseline in the main comparison table, but the method also uses the official core for the current strongest version.
   - This is a methodological caveat for writing. The current safest framing is a lightweight reliability-guarded reconstruction framework built on strong graph imputation cores.

2. Physics residual bank:
   - Generates multiple residual-aware candidate corrections.
   - Physics does not directly replace the prediction.
   - Physics contributes by judging local correction utility and by promoting residual-consistent corrections.

3. Temporal evidence bank:
   - Important for sensor failure.
   - Main sensor-failure evidence shows temporal evidence is the dominant contributor in that scenario.

4. Failure-mode score:
   - Estimates whether the current missing pattern resembles true sensor failure.
   - Based on node-level outage contrast and long missing gaps.
   - Interpretable statistic: sensor failure score is high, random/incident score is low.

5. Non-sensor conservative selector:
   - Prevents temporal evidence from over-correcting random missing or incident settings, especially on METR-LA.
   - This is the main V5 improvement over V4.

6. Harm-aware correction:
   - The method avoids correction when candidate correction is likely to harm the strong reconstruction.

## Known Caveats

1. The current strongest method uses official MagiNet as the reconstruction core.
   - This is strong numerically.
   - For writing, frame LiteTrust-FMG as a reliability-guarded correction framework that can sit on a strong reconstruction backbone.
   - Avoid claiming MagiNet was not used if main results use the official core.

2. Sensor failure gain is small.
   - Average gain is positive: +1.62%.
   - Wins are 10/15.
   - The scenario is still useful because temporal evidence ablation is strong, but do not overclaim massive sensor-failure improvement.

3. METR-LA is weaker than PEMS datasets.
   - V5 fixes V4's negative METR-LA average.
   - Gain is now +3.90%, but lower than PEMS datasets.
   - Explanation: METR-LA is speed-only, so the physics residual bank is less informative than multivariate flow/speed/occupancy PEMS-style residuals.

4. No full prediction arrays were saved in the completed main table.
   - Existing artifacts are mostly csv/json/md/log.
   - If a visual case study needs true/pred/mask curves, rerun one small case and modify the script to save predictions.

5. Do not keep making small training tweaks.

```text
Existing traffic reconstruction models either rely on data-driven imputation or apply physics constraints too uniformly.

```
